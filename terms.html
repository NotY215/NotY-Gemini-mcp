2. Description of Service

NotY-Gemini-MCP is a desktop application that integrates Google's Gemini AI with Visual Studio Code through the Model Context Protocol (MCP). The Software provides AI-assisted coding capabilities, including but not limited to:

  • Code analysis and optimization suggestions
  • Error detection and automated fixes
  • Natural language programming assistance
  • Project-level context understanding
  • Terminal-based AI interaction within VS Code

3. Data Handling and Privacy

3.1 Local Data Storage

Your Gemini API key is encrypted using AES-256 encryption and stored locally in your user directory (%appdata%/gemini-mcp/key.db). The encryption key is derived from your system's unique identifiers, ensuring that the stored data remains secure and inaccessible to third parties.

3.2 Data Transmission

When you use the Software to interact with Google's Gemini AI, the following data may be transmitted to Google's servers:

  • Your Gemini API key (for authentication purposes)
  • Code snippets and project files you choose to analyze

  • Error logs and debugging information

All data transmission occurs over encrypted HTTPS connections to Google's API endpoints. However, the developers cannot guarantee the security of data transmitted over the internet.
